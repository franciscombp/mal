🎯 bp-button

Botón de acción del Solar Design System con 5 variantes y múltiples estados.

Características

  • 5 variantes de estilo (primary, secondary, tertiary, accent, destructive)
  • 6 estados automáticos (default, hover, focus, pressed, disabled, loading)
  • 3 tamaños disponibles (default, small, large)
  • Ícono integrado opcional
  • 100% accesible (WCAG 2.1 AA)
  • Respeta prefers-reduced-motion
  • Completamente responsive
  • HTML semántico + CSS puro (sin frameworks)

Accesibilidad

El componente está completamente accesible:

  • Keyboard Navigation: Funciona perfecto con Tab y Enter
  • Focus Visible: Ring azul visible al tabular
  • Screen Readers: Semántica HTML correcta
  • Aria Attributes: Soporte para aria-busy, aria-disabled
  • Reduced Motion: Spinner se detiene si prefers-reduced-motion
  • Color Contrast: Cumple WCAG AA (≥ 4.5:1)

Ejemplos ARIA

<!-- Estado de carga --> <button class="bp-button" aria-busy="true"> <span class="bp-button__label">Cargando...</span> </button> <!-- Deshabilitado accesiblemente --> <button class="bp-button" disabled aria-disabled="true"> <span class="bp-button__label">No disponible</span> </button> <!-- Acción destructiva --> <button class="bp-button" data-variant="destructive" aria-label="Eliminar este elemento"> <span class="bp-button__label">Eliminar</span> </button>

Uso en Código

Instalación

<!-- Incluye el CSS --> <link rel="stylesheet" href="/ds/mal/bp-button.css">

HTML Básico

<button class="bp-button" data-variant="primary"> <span class="bp-button__label">Aceptar</span> </button>

Con Ícono

<button class="bp-button" data-variant="primary"> <svg class="bp-button__icon" viewBox="0 0 24 24"> <!-- tu SVG aquí --> </svg> <span class="bp-button__label">Agregar</span> </button>

JavaScript para Estado de Carga

const btn = document.querySelector('.bp-button'); // Mostrar cargando btn.setAttribute('aria-busy', 'true'); btn.disabled = true; // Simular petición await fetch('/api/data'); // Ocultar cargando btn.removeAttribute('aria-busy'); btn.disabled = false;
